# 04. ドキュメントとコメントだけ触る

## 変更

`README.md` に1行足し、`app/money.py` のコメントを2行に折り返す。
実行される行は1行も変わっていない。

## 期待

**何も起きないこと。** これは誤検知の検査であって、賢く振る舞うことを求めていない。

- claim の状態は全て据え置き。stale も orphaned も invalidated も1つも出ない
- 訂正履歴に行が増えない
- オリエンテーションの書き直しも走らない
- 学習カバレッジ・採掘カバレッジのどちらも変わらない

## 判定

1つでも状態が動いたら誤検知。行番号がずれたことをアンカーの変化と誤認していないか、
差分があること自体を「地図を書き直す理由」にしていないかを見る。

同期のたびに何かしら動く作りになっていると、本当に見るべき 01 や 03 の変化が
ノイズに埋もれる。ここが静かであることが、他の検査結果の信頼性を支える。
