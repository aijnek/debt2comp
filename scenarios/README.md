# 差分シナリオ

`samples/expense/` に後から変更を加え、Skill の起動時同期（再検証・追加抽出・
地図の追随）が期待通りに動くかを見るための仕掛け。

**このディレクトリは Skill を起動する作業ディレクトリの外に置いてある。**
サンプルの中に置くと、Skill が期待結果を読んでから答えることになり検査にならない。

## 使い方

```bash
scenarios/01-add-unauthorized-route/apply.sh   # 変更を当てる
# ここで Skill の同期を走らせ、expect.md と突き合わせる
git checkout -- samples/expense && git clean -fd samples/expense   # 元に戻す
```

`apply.sh` は当てる前に対象の文字列が在ることを確かめ、無ければ失敗して止まる。
サンプル側を書き換えたらシナリオも追随させること。

## 一覧

| # | 何をするか | 何を見るか |
|---|---|---|
| 01 | 認可のないルートを1本足す | verify の再実行が落ちること。新規ファイルが un-claimed 領域として見えること |
| 02 | 挙動を変えずに関数名を変える | verified は生き残り、asserted だけが orphaned に落ちること |
| 03 | 承認しきい値の値を変える | どの verify も落ちないまま claim の内容だけが偽になる場合に、訂正まで至れるか |
| 04 | ドキュメントとコメントだけ触る | **何も起きないこと**（誤検知の検査） |
| 05 | 新しいモジュールを足す | 追加抽出が走り、地図と採掘カバレッジが追随すること |
